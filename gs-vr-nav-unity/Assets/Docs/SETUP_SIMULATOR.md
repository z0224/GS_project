# GS-VR-Nav Unity Setup

The simulator now uses Blosm-only map geometry.

Required assets:

- `Assets/StreamingAssets/SplatScenes/aligned_scene.ply`
- `Assets/StreamingAssets/Alignment/map_alignment.json` (recommended, generated by map-to-scene ICP)
- `Assets/External/BlosmMap/Blosm_Map.fbx`

To generate automatic Blosm map alignment, run:

```powershell
Set-Location D:\desktop\gs_nv\gs-vr-nav
python -m geo_alignment.icp_refinement `
  --mode map-to-scene `
  --input-ply ..\gs-vr-nav-unity\Assets\StreamingAssets\SplatScenes\aligned_scene.ply `
  --osm-json ..\outputs\osm\site_a\osm_data.json `
  --output-map-alignment ..\gs-vr-nav-unity\Assets\StreamingAssets\Alignment\map_alignment.json `
  --unity-y-offset -1
```

To generate the Blosm asset, select `NavMeshManager`, set `GeoAlignmentLoader > Blender Executable Path` if needed, then run the context menu item:

```text
Generate Blosm Map Asset
```

At runtime, `GeoAlignmentLoader` instantiates the FBX under:

```text
NavMeshManager/Blosm_MapGeometry
```

Road/path meshes are used for Walkable checks. Building meshes are used for physical blocking through `MeshCollider`.

Keep `NavMeshManager` at identity. `GeoAlignmentLoader` applies the JSON transform to `Blosm_MapGeometry` automatically.
